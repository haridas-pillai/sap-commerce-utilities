
# SAP Commerce Cloud Utilities

A collection of practical utilities, scripts, queries, and technical examples for SAP Commerce Cloud (Hybris).

This repository aims to help SAP Commerce developers, technical leads, and architects solve common development, administration, integration, and troubleshooting challenges.

## 🎯 Objectives

- Share reusable SAP Commerce Cloud Groovy scripts.
- Provide commonly used FlexibleSearch queries.
- Maintain useful ImpEx examples.
- Document troubleshooting techniques.
- Share performance optimization and operational best practices.
- Demonstrate practical SAP Commerce engineering knowledge.

## 🛠️ Technology Stack

- SAP Commerce Cloud 2211
- Java
- Spring Framework
- Groovy
- FlexibleSearch
- ImpEx
- Apache Solr
- SAP Commerce Cloud v2 (CCv2)
